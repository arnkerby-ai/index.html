DCCFI SPIN THE WHEEL — Quick Setup
====================================

Open index.html.html in your browser and keep shepherd-and-sheep.png
and Untitled Design.png in the same folder.

FEATURES
--------
• Spin the Wheel with 3-second smooth spin
• The shepherd and sheep dance and show their catchphrases in silent
  speech bubbles while the wheel spins. Both immediately return to
  looping standby animations when the wheel stops.
• CRUD for participant names:
    - Add  : type name + press Enter or click "+ Add"
    - Edit : click ✏️ icon, change name, click 💾 or press Enter
    - Delete: click 🗑️ icon
• Save Names keeps the current list in this browser and downloads
  dccfi-names.txt with one name per line.
• Upload Names adds names from a UTF-8 .txt file with one name per line.
  Blank lines, duplicates, and names over 40 characters are skipped.
• Confetti burst when a winner is selected
• The wheel and mascot artwork work offline. Google Fonts load when
  an internet connection is available.
